# Code de conduite

Enora est un projet ouvert à tous. Pour que chacun s'y sente bien :

- **Soyez respectueux et bienveillant**, quels que soient le niveau, l'origine, la langue ou les opinions des autres.
- **Critiquez le code, pas les personnes.** Les remarques sont constructives et expliquées.
- **Accueillez les débutants.** Une question n'est jamais bête.
- **Aucune tolérance** pour le harcèlement, les insultes, les propos discriminatoires ou la publication d'informations privées.

En cas de problème, contactez le mainteneur via la page GitHub du projet (Geld237). Les comportements contraires à ce code peuvent entraîner la suppression de messages ou l'exclusion du projet.
