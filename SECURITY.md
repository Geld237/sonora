# Sécurité

Si vous découvrez une faille de sécurité (fuite de données, accès au compte d'un autre utilisateur, exécution de code…), **ne la publiez pas dans une issue publique**.

Signalez-la de façon privée sur GitHub : onglet **Security** → **Report a vulnerability**. Décrivez le problème, comment le reproduire et la version d'Enora concernée.

Vous recevrez une réponse dès que possible, et la faille sera corrigée avant d'être rendue publique.
